# 🗨️ Real-Time Chat App

This is a simple real-time chat application built using **Node.js**, **Express**, and **WebSocket**. Conversations are stored on the server, so users sharing the same chatroom URL can view the full message history.

## 🌍 Live Demo

Try it here:  
👉 [https://chat-tbyp.onrender.com/](https://chat-tbyp.onrender.com/)

## ⚙️ Features

- Real-time messaging between multiple users.
- Message history is stored server-side.
- Clean and simple user interface.
- Hosted for free on [Render](https://render.com).

## 🛠️ Tech Stack

- [Node.js](https://nodejs.org/)
- [Express.js](https://expressjs.com/)
- [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket)
- HTML, CSS, JavaScript (Frontend)
- [Render](https://render.com) for deployment

## 📦 Getting Started (Local Setup)

1. Clone the repository:

```bash
git clone https://github.com/zajurin/chat.git
cd chat.git


2. Install dependencies:

bash
npm install

3. Start the development server:

node index.js


4. Visit the app at: http://localhost:3000
